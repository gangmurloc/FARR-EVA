# Public release checklist

Unchecked items are follow-up tasks; the repository currently grants no
open-source reuse rights until a license is selected.

- [x] Raw datasets and generated candidate pools excluded
- [x] Multi-gigabyte model checkpoints excluded
- [x] Logs, manuscripts, title pages, and author metadata excluded
- [x] Machine-specific absolute paths removed from included code
- [x] Frozen selector artifact checked for local identity strings
- [x] Unit tests and artifact smoke test included
- [x] Test-C result and post-hoc portable diagnostic separated
- [x] Test-D IDs and uncompleted outcomes excluded
- [ ] Author chooses and adds an open-source license
- [ ] Author confirms repository name and description
- [ ] Test-D status updated after the locked run completes
- [ ] Final repository scan passes before changing visibility to public
